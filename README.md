The text is set in Liberation Sans (SIL Open Font License 1.1): the glyph
outlines in `fontdata.py` were extracted from the Liberation Sans Bold and
Regular fonts at build time and are embedded as data, so the program is
self-contained and uses only the Python standard library at runtime.
