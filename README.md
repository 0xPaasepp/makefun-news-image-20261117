# makefun-news-image-20261117

THE WORLD'S NEWS IN ONE PICTURE — the world's news of Tuesday, 17 November 2026, drawn as one front page by a Python program (45 stories).

The text is set in Liberation Sans (SIL Open Font License 1.1) with a
DejaVu Serif Bold masthead and headlines (free license): the glyph
outlines in `fontdata.py` and `serifdata.py` were extracted from the
Liberation Sans Bold/Regular and DejaVu Serif Bold fonts at build time
and are embedded as data, so the program is self-contained and uses only
the Python standard library at runtime. Land outlines in `land.py` come
from Natural Earth 110m country data (public domain), simplified at
build time.
